Babel plugin to cherry-pick ES module imports.

### Installation

[](https://github.com/avocadowastaken/babel-plugin-direct-import#installation)

```shell
npm install --save-dev babel-plugin-direct-import
```

### Example

[](https://github.com/avocadowastaken/babel-plugin-direct-import#example)

**In**

```js
import { Button, colors, ThemeProvider } from "@mui/material";
import {
  ChevronLeft as ChevronLeftIcon,
  ChevronRight as ChevronRightIcon,
} from "@mui/icons-material";
```

**Out**

```js
import Button from "@mui/material/Button/Button.js";
import * as colors from "@mui/material/colors/index.js";
import ThemeProvider from "@mui/system/esm/ThemeProvider/ThemeProvider.js";
import ChevronLeftIcon from "@mui/icons-material/esm/ChevronLeft.js";
import ChevronRightIcon from "@mui/icons-material/esm/ChevronRight.js";
```

### Usage

[](https://github.com/avocadowastaken/babel-plugin-direct-import#usage)

#### **Via .babelrc (Recommended)**

[](https://github.com/avocadowastaken/babel-plugin-direct-import#via-babelrc-recommended)

**.babelrc**

```json
{
  "plugins": [\
    [\
      "babel-plugin-direct-import",\
      {\
        "modules": ["@mui/system", "@mui/material", "@mui/icons-material"]\
      }\
    ]\
  ]
}
```

#### **Via Node API**

[](https://github.com/avocadowastaken/babel-plugin-direct-import#via-node-api)

```js
require("babel-core").transform("code", {
  plugins: [\
    [\
      "babel-plugin-direct-import",\
      {\
        modules: ["@mui/system", "@mui/material", "@mui/icons-material"],\
      },\
    ],\
  ],
});
```

### Limitations

[](https://github.com/avocadowastaken/babel-plugin-direct-import#limitations)

##### Transformation of namespace imports:

[](https://github.com/avocadowastaken/babel-plugin-direct-import#transformation-of-namespace-imports)

Namespace imports are hard to analyze, that's why we skip them.

```js
import * as MUI from "@mui/material";

return (props) => <MUI.Checkbox {...props} />;
```

##### Mapping of variable exports:

[](https://github.com/avocadowastaken/babel-plugin-direct-import#mapping-of-variable-exports)

```js
import * as colors from "./colors";

export const blue = colors.blue;
export const cyan = colors.cyan;
export const getDefaultColor = () => red;
```

### Integrations

[](https://github.com/avocadowastaken/babel-plugin-direct-import#integrations)

#### Next.js

[](https://github.com/avocadowastaken/babel-plugin-direct-import#nextjs)

```js
// babel.config.js

module.exports = (api) => {
  const target = api.caller((caller) => caller.target);

  api.cache.using(() => JSON.stringify({ target }));

  const presets = ["next/babel"];
  const plugins = [];

  // Enable optimizations only for the `web` bundle.
  if (target === "web") {
    plugins.push([\
      "babel-plugin-direct-import",\
      { modules: ["@mui/lab", "@mui/material", "@mui/icons-material"] },\
    ]);
  }

  return { presets, plugins };
};
```

### Migration

[](https://github.com/avocadowastaken/babel-plugin-direct-import#migration)

#### 0.5.0 to 0.6.0

[](https://github.com/avocadowastaken/babel-plugin-direct-import#050-to-060)

After migration to Babel v7 it's impossible to pass arrays as configs, and now you have to pass an object with `modules` property:

Before:

```json
{
  "plugins": [["babel-plugin-direct-import", ["@material-ui/core"]]]
}
```

After:

```json
{
  "plugins": [\
    ["babel-plugin-direct-import", { "modules": ["@material-ui/core"] }]\
  ]
}
```
