deno bundle
===========

Info

`deno bundle` is currently an experimental subcommand and is subject to changes.

`deno bundle` combines your module and all of its dependencies into a single JavaScript file, using [esbuild](https://esbuild.github.io/)
 under the hood. It is useful for deploying or distributing a project as a single optimized file, but it is not currently intended as a replacement for complex or interactive build tools such as [Vite](https://vite.dev/)
 or [webpack](https://webpack.js.org/)
.

Basic usage [Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#basic-usage)

------------------------------------------------------------------------------------------------

›\_

    deno bundle -o output.js main.ts
    

Without `-o`/`--output`, the bundle is written to standard output. The output file can then be run with Deno or in other JavaScript runtimes:

›\_

    deno run output.js
    

Common options [Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#common-options)

------------------------------------------------------------------------------------------------------

Target a platform with `--platform` (`deno` by default, or `browser`), shrink the output with `--minify`, and emit source maps with `--sourcemap`:

›\_

    deno bundle --platform=browser --minify --sourcemap -o dist/app.js main.ts
    

Split shared code into separate chunks with `--code-splitting` and an output directory:

›\_

    deno bundle --code-splitting --outdir dist/ main.ts worker.ts
    

Keep a dependency out of the bundle with `--external`:

›\_

    deno bundle --external npm:sharp -o output.js main.ts
    

Generate TypeScript declarations alongside the JS output with `--declaration`. Deno rolls up the types for each entry point into a single self-contained `.d.ts` file:

›\_

    deno bundle main.ts --outdir dist --declaration
    # Produces dist/main.js and dist/main.d.ts
    

Type checking [Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#type-checking)

----------------------------------------------------------------------------------------------------

`deno bundle` does not type-check your code by default. Enable type-checking with the `--check` flag:

›\_

    # type-check local modules while bundling
    deno bundle --check -o output.js main.ts
    
    # also type-check remote modules
    deno bundle --check=all -o output.js main.ts
    

You can also skip type-checking explicitly with `--no-check`, and `--no-check=remote` ignores diagnostics from remote modules only.

The `browser` field [Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#the-browser-field)

--------------------------------------------------------------------------------------------------------------

When bundling with `--platform=browser`, Deno honors the npm `browser` field in a dependency's `package.json`, including its object form. The object maps modules to browser-specific replacements:

    {
      "browser": {
        "./server.js": "./client.js",
        "crypto": false,
        "foo": "./shims/foo.js"
      }
    }
    

*   A relative-path key remaps a resolved file to a browser-specific one (`./server.js` becomes `./client.js`).
*   A bare-specifier key remaps an import (`foo` becomes `./shims/foo.js`). A leading `node:` prefix is stripped before lookup, so `import "node:crypto"` matches the `"crypto"` key.
*   A value of `false` excludes the module: the bundler substitutes an empty stub.

For more on bundling strategies with Deno, see the [Bundling](https://docs.deno.com/runtime/reference/bundling/)
 guide.

Command line usage:

    bundle

Output a single JavaScript file with all dependencies

Options [Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options)

----------------------------------------------------------------------------------------

`--allow-import, -I`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-allow-import)

Allow importing from remote hosts. Optionally specify allowed IP addresses and host names, with ports as necessary. Default value: deno.land:443,[jsr.io:443](http://jsr.io:443/)
,[esm.sh:443](http://esm.sh:443/)
,[raw.esm.sh:443](http://raw.esm.sh:443/)
,[cdn.jsdelivr.net:443](http://cdn.jsdelivr.net:443/)
,[raw.githubusercontent.com:443](http://raw.githubusercontent.com:443/)
,[gist.githubusercontent.com:443](http://gist.githubusercontent.com:443/)
.

`--allow-scripts`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-allow-scripts)

Allow running npm lifecycle scripts for the given packages Note: Scripts will only be executed when using a node\_modules directory (`--node-modules-dir`).

`--cert`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-cert)

Load certificate authority from PEM encoded file.

`--check`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-check)

Enable type-checking. This subcommand does not type-check by default; pass `--check=all` to also type-check remote modules. Alternatively, use the 'deno check' subcommand.

`--code-splitting`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-code-splitting)

Enable code splitting.

`[--config, -c](https://docs.deno.com/go/config) `

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-config)

Configure different aspects of deno including TypeScript, linting, and code formatting. Typically the configuration file will be called `deno.json` or `deno.jsonc` and automatically detected; in that case this flag is not necessary.

`--declaration`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-declaration)

Generate .d.ts declaration files alongside the bundle.

`--deny-import`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-deny-import)

Deny importing from remote hosts. Optionally specify denied IP addresses and host names, with ports as necessary.

`--external`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-external)

`--format`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-format)

`--frozen-lockfile`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-frozen-lockfile)

Error out if lockfile is out of date.

`[--import-map](https://docs.deno.com/runtime/manual/basics/import_maps) `

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-import-map)

Load import map file from local file or remote URL.

`--inline-imports`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-inline-imports)

Whether to inline imported modules into the importing file \[default: true\]

`--keep-names`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-keep-names)

Keep function and class names.

`--lock`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-lock)

Check the specified lock file. (If value is not provided, defaults to "./deno.lock").

`--min-dep-age`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-min-dep-age)

(Unstable) The age in minutes, ISO-8601 duration or RFC3339 absolute timestamp (e.g. '120' for two hours, 'P2D' for two days, '2025-09-16' for cutoff date, '2025-09-16T12:00:00+00:00' for cutoff time, '0' to disable).

`--minify`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-minify)

Minify the output.

`--no-check`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-no-check)

Skip type-checking. If the value of "remote" is supplied, diagnostic errors from remote modules will be ignored.

`--no-config`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-no-config)

Disable automatic loading of the configuration file.

`--no-lock`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-no-lock)

Disable auto discovery of the lock file.

`--no-npm`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-no-npm)

Do not resolve npm modules.

`--no-remote`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-no-remote)

Do not resolve remote modules.

`--node-modules-dir`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-node-modules-dir)

Selects the node\_modules directory mode for npm packages (not a path). One of: auto (create a local node\_modules directory and install npm packages into it), manual (use the existing local node\_modules directory, do not modify it), none (do not use a local node\_modules directory; resolve npm packages from the global cache). Defaults to auto when the flag is passed without a value.

`--node-modules-linker`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-node-modules-linker)

Sets the linker mode for npm packages (isolated or hoisted).

`--outdir`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-outdir)

Output directory for bundled files.

`--output, -o`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-output)

Output path\`.

`--packages`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-packages)

How to handle packages. Accepted values are 'bundle' or 'external'.

`--platform`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-platform)

Platform to bundle for. Accepted values are 'browser' or 'deno'.

`--reload, -r`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-reload)

Reload source code cache (recompile TypeScript). With no value, reloads everything. Pass a comma-separated list of specifiers to reload only those modules; npm: reloads all npm modules; npm:chalk reloads a single npm module; jsr:@std/http/file-server,jsr:@std/assert/assert-equals reloads specific modules.

`--sourcemap`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-sourcemap)

Generate source map. Accepted values are 'linked', 'inline', or 'external'.

`--unsafely-ignore-certificate-errors`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-unsafely-ignore-certificate-errors)

DANGER: Disables verification of TLS certificates.

`--vendor`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-vendor)

Toggles local vendor folder usage for remote modules and a node\_modules folder for npm packages.

`--watch`

[Jump to heading#](https://docs.deno.com/runtime/reference/cli/bundle/#options-watch)

Watch and rebuild on changes.
