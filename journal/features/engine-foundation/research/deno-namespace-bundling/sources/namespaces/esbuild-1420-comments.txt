This is a fairly advanced optimization; it was only added in Webpack 5 for example, and is not present in Webpack 4 (see [webpack/webpack#9607](https://github.com/webpack/webpack/issues/9607)).\r\n\r\nIf deep tracking is currently out of scope, maybe a good starting point would be an opt-in flag which would treat namespaced imports not as objects, but as aliases (assignments of sorts) _right from the start_ (from within, i.e. from the namespaced export; not from the usage), essentially completely bypassing the object semantics:\r\n\r\n###### [TRY](https://esbuild.github.io/try/#YgAwLjE4LjQALS1idW5kbGUgLS10cmVlLXNoYWtpbmcAZQBlbnRyeS5qcwBpbXBvcnQgKiBhcyBGdW5jdGlvbnMgZnJvbSAnLi9mdW5jdGlvbnMnCmNvbnNvbGUubG9nKEZ1bmN0aW9ucy5hZGQoMSwgMikpAABmdW5jdGlvbnMuanMAZXhwb3J0IGZ1bmN0aW9uIGFkZCAoYSwgYikgeyByZXR1cm4gYSArIGIgfQpleHBvcnQgZnVuY3Rpb24gc3ViIChhLCBiKSB7IHJldHVybiBhIC0gYiB9)\r\n\r\n```ts\r\n// entry.js\r\nimport * as Functions from './functions'\r\nconsole.log(Functions.add(1, 2))\r\n\r\n// functions.js\r\nexport function add (a, b) { return a + b }\r\nexport function sub (a, b) { return a - b }\r\n```\r\n\r\n\r\nProposed output\r\n\r\n```diff\r\n  (() => {\r\n    // functions.js\r\n-  function add(a, b) {\r\n+  function Functions$add(a, b) {\r\n      return a + b;\r\n    }\r\n\r\n    // entry.js\r\n-   console.log(add(1, 2));\r\n+   console.log(Functions$add(1, 2));\r\n  })();\r\n```\r\n\r\n\r\nWith this transformation in place, it should be much easier to \"propagate\" the tree-shaking mechanism through modules and namespaced re-exports:\r\n\r\n###### [TRY](https://esbuild.github.io/try/#YgAwLjE4LjQALS1idW5kbGUgLS10cmVlLXNoYWtpbmcAZQBlbnRyeS5qcwBpbXBvcnQgeyBGdW5jdGlvbnMgfSBmcm9tICcuL2FwaScKY29uc29sZS5sb2coRnVuY3Rpb25zLmFkZCgxLCAyKSkAAGFwaS5qcwBleHBvcnQgKiBhcyBGdW5jdGlvbnMgZnJvbSAnLi9mdW5jdGlvbnMnAABmdW5jdGlvbnMuanMAZXhwb3J0IGZ1bmN0aW9uIGFkZCAoYSwgYikgeyByZXR1cm4gYSArIGIgfQpleHBvcnQgZnVuY3Rpb24gc3ViIChhLCBiKSB7IHJldHVybiBhIC0gYiB9)\r\n\r\n```ts\r\n// entry.js\r\nimport { Functions } from './api'\r\nconsole.log(Functions.add(1, 2))\r\n\r\n// api.js\r\nexport * as Functions from './functions'\r\n\r\n// functions.js\r\nexport function add (a, b) { return a + b }\r\nexport function sub (a, b) { return a - b;\r\n-   }\r\n\r\n    // entry.js\r\n-   console.log(functions_exports.add(1, 2));\r\n+   console.log(Functions$add(1, 2));\r\n  })();\r\n```\r\n\r\n\r\nThe issue is, of course, that you're losing the compliant semantics of an object (spec calls them [exotic objects](https://tc39.es/ecma262/#sec-module-namespace-exotic-objects)) when used directly.
